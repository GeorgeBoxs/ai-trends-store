## 💡 Idea of the Day
**Decision-gated merge bot.** Combine the AWS merge-gate pattern with the Decisions API: a GitHub App (Next.js + Postgres) that on every PR runs ~20 rubric/yes-no questions through `gemini-decision-1` (tests touched? risky files? scope creep vs PR title? secrets? migration without rollback?) at roughly zero cost and sub-second latency, posts a confidence-scored checklist, and only when a score crosses a threshold dispatches a Claude Code fixer agent in a worktree. Free for public repos (distribution), $19/repo/month for private; later sell the rubric packs as skills. Evidence this layer sells: Skillry (curated agent skills, solo, Stripe-verified $5,288 MRR three months in, https://trustmrr.com/startup/skillry) and Skillbox (#5 on Product Hunt Nov 11, skill sync + prompt-injection scanning).
