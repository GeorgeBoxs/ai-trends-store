## 🔥 Top 3 — Do Today
1. **SECURITY: backdoored "Claude Code" extension on the Cursor marketplace (v2.1.312 / 2.1.313)** — Reported by Phorion/OpenSourceMalware on Oct 30: injected code in extension.js adds an attacker SSH key (comment `svc-telemetry`), opens a reverse tunnel to 134.209.82[.]225, persists via LaunchAgent/cron/scheduled task. Cursor served it ~11h on Oct 29 and removed it; Cursor says at most ~5,000 users. Anthropic's only public remark found is an employee HN comment saying the official VS Code marketplace and Open VSX copies and the npm package are unaffected (sources conflict on Open VSX; no formal Anthropic statement found). Uninstalling does NOT remove the backdoor. **Try it (10 min):** `ls ~/.cursor/extensions | grep anthropic.claude-code` (and other IDE dirs); `grep -n svc-telemetry ~/.ssh/authorized_keys`; `ls ~/.config/.smt* ~/Library/LaunchAgents/com.apple.sysmond.plist`; `ps aux | grep -E "134.209.82.225"`. If any hit: remove persistence + key, rotate credentials. · https://phorion.io/blog/offical-claude-code-vsx-compromise/ · HN: https://news.ycombinator.com/item?id=50302425
2. **Claude Code v2.1.314 → v2.1.316** — `permissions.blockWritesOutsideWorkingDirectories` hard-blocks Write/Edit/NotebookEdit outside the cwd in every mode; `CLAUDE_CODE_SUBAGENT_EFFORT` sets subagent effort; `CLAUDE_CODE_DISABLE_ULTRATHINK`. Why: cheap blast-radius limiter, relevant given #1. **Try it:** `claude update`, add `"permissions": {"blockWritesOutsideWorkingDirectories": true}` to ~/.claude/settings.json, set `CLAUDE_CODE_SUBAGENT_EFFORT=low` for fan-out runs and compare `/usage`. · https://github.com/anthropics/claude-code/releases
3. **Fast mode on Opus 4.8 is removed Nov 30** — requests will error, not fall back (per v2.1.316 notes). **Try it:** grep your scripts/settings for Opus 4.8 fast mode and move to Opus 5.5 now. · https://github.com/anthropics/claude-code/releases
