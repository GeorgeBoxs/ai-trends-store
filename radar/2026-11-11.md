## 🔥 Top 3 — Do Today
1. **Fable 5.2 prompting guide (Anthropic docs)** — official list of prompt lines that change Fable 5.2 behavior, with measured effects. Why: your CLAUDE.md, skills and Agent SDK system prompts were tuned for older models, and some lines now cost tokens or block work.
   **Try it (30 min):**
   - In a repo you own, add to CLAUDE.md: `This codebase is yours: what it's for and how it's built are your call, and you'll keep building on it.` Anthropic's tests: duplicate code got merged in about half of tries vs under a tenth without it. Cost: about 1.5x output tokens and unrequested changes, so review the diff, not the summary. Leave it out of client repos.
   - For headless runs at low/medium effort, paste the guide's "Finishing work" block into the system prompt. Anthropic's replay: about half as many sessions ended with doable work left, for about 30% more output tokens.
   - Delete stale lines: "answer directly without deliberating" (no effect at medium+; lower effort instead), in-prompt token budgets, standing "delegate to subagents" lines, and old "never retry" notes in memory files.
   https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-2
2. **GoogleChrome/modern-web-guidance** — skills pack from the Chrome, Edge, Firefox and MDN teams that moves coding agents off legacy JS/CSS patterns: 250 modern web features, 203 use cases, with browser-compat data. ⭐3.5k, Apache-2.0, 330 points on Show HN. Why: fixes the "agent writes 2019 frontend" problem in your Next.js work with one install. Ships plugin manifests for Claude Code, Codex, Cursor and Gemini.
   **Try it (15 min):** `npx modern-web-guidance@latest legacy-scan .` in a frontend repo to see what it flags, then `npx modern-web-guidance@latest install`. The repo links an eval dashboard but the README gives no scores.
   https://github.com/GoogleChrome/modern-web-guidance
3. **Gemini 4 Carbon is GA (`gemini-4-carbon`)** — Google's frontier agentic-coding model, opened to everyone on Nov 10. Intro price $2/$10 per Mtok through Nov 30 (then $4/$20 per Simon Willison). Why: a frontier model at a quarter of Fable 5.2's $8/$40 list price for three weeks; a good time to run your own evals. I found no independent benchmarks today.
   **Try it (30 min):** `llm install -U llm-gemini && llm -m gemini-4-carbon "<your hardest recent prompt>"`, then run the same real ticket through it and through Fable 5.2 and compare the diffs and cost. Gemini CLI support: unverified.
   https://aistudio.google.com/docs/changelog · https://github.com/simonw/llm-gemini/releases/tag/0.36

## 🛠 Claude Code / Codex / Agents
- **Fable 5.2 rejects edited history** — the API now enforces a prefix check for every account: if your harness changes `system`, `tools`, or an earlier message while sending thinking blocks back, the request can return a 400. → In Agent SDK or custom loops, keep history append-only, put new instructions in the newest turn, and use compaction or context editing to shorten history. Test resumed stored conversations before you ship a prompt change. Same guide as Top 3 #1.
- **Silent long turns on Fable 5.2** — progress updates arrive as `thinking` blocks that are empty at the default `thinking.display: "omitted"`. → Set `display: "updates"` (beta header `thinking-display-updates-2026-08-18`) and render them, or your UI looks frozen. Same guide.
- **Codex 0.167.1** (Nov 10) — small patch: opt-in `incremental_tools_legacy` flag, limited to Amazon Bedrock providers. Alphas 0.169.0-alpha.9/10 shipped with no notes. → Nothing to do unless you run Codex on Bedrock. https://github.com/openai/codex/releases
- **Claude Whiteboards + Claude Sheets (beta), Claude Data (GA, renamed from Dashboards)** — Nov 10, all paid plans; Data connects to BigQuery, Redshift, ClickHouse, PostHog and others. No API, MCP or Claude Code hook is mentioned. → Use Data for a quick metrics page from Postgres-adjacent warehouses. Also note that Anthropic now ships sheets and dashboards natively, so generic "AI spreadsheet" products have a new competitor. https://claude.com/resources/articles/sheets-whiteboards-data
- **AlphaProof Code (Google DeepMind)** — Nov 10: Gemini Carbon agents wrote over six million lines of Lean to prove security properties of Signal's compiled code in four weeks, flagging about 1% for human review. Artifacts are being open-sourced; there is no API or product. → Not usable today. The pattern to keep: agents write proofs, a checker verifies, humans review only the specs. https://deepmind.google/blog/introducing-alphaproof-code/
