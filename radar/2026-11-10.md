## 🔥 Top 3 — Do Today
1. **Claude Fable 5.2 (`claude-fable-5-2`)** — new default Fable model, 1M context, $8/$40 per Mtok (fast mode $16/$80, up to 2.5x faster). Anthropic's own numbers vs Opus 5.5: FrontierSWE v2 69.9 vs 62.3; FrontierCode 2.0 49.1 vs 45.5 (vendor benchmarks, unverified independently). Matches Opus 5.5 at ~half cost/task at High effort.
   **Try it:** `claude update && claude --model claude-fable-5-2`, then run one real refactor at medium effort and compare token use against Opus 5.5. Try it as orchestrator: Fable plans, cheaper subagents execute. https://www.anthropic.com/claude-fable-and-mythos-5-2
2. **Claude Code v2.1.319–2.1.322** — `permissions.denyInsteadOfPrompting` (unattended runs don't stall on prompts), MCP long tasks auto-background, `/claude-api latency-optimize`, security fixes (MCP OAuth secret leakage on redirect, sandbox bypass for read-only Bash, cp/mv deny rules).
   **Try it:** `claude update`, add `"permissions": {"denyInsteadOfPrompting": true}` to settings for headless/CI runs. https://github.com/anthropics/claude-code/releases
3. **Strands Decider (Amazon)** — small decision model for closed-choice classification/routing; reported ~98% cheaper and 78% faster than Sonnet 4.6 on ticket labeling (self-reported, list prices).
   **Try it:** pick one LLM classifier in your stack (ticket tags, intent routing); clone `strands-labs/strands-decider` (per the post), run side-by-side with your LLM on 200 labeled rows. Sort JSON keys (key order shifted probabilities by up to 0.19). https://strandsagents.com/blog/amazon-saves-millions-replacing-sonnet-with-strands-decider/
