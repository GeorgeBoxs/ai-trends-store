## 🔥 Top 3 — Do Today
1. **Claude Code v2.1.323: Code Mode (experimental) + plugin version pinning** — Code Mode is opt-in: Claude writes JavaScript that calls its tools, so it can chain tool calls in one step. `plugin.json` now takes `engines["claude-code"]`, and plugins outside that version range don't load. · Why it matters: Code Mode is the "code instead of N tool calls" pattern that OpenCode and Docker already ship, now in Claude Code. It should mean fewer round-trips on multi-file and MCP-heavy work. `engines` stops your plugins breaking on auto-update. · **Try it:** `claude update && claude --version` (should print 2.1.323). Turn Code Mode on per the linked docs and rerun a recent multi-MCP task, then compare turns and `/usage`. Add `"engines": {"claude-code": ">=2.1.323"}` to your plugins and run `claude plugin validate --strict`. The docs page `code.claude.com/docs/en/code-mode` returned 404 when I fetched it, so the exact toggle is unverified. · https://github.com/anthropics/claude-code/releases
2. **Gemini 4 Hydrogen + Orchestrator (Antigravity, Nov 12)** — Hydrogen is a cheaper Gemini 4 model with low/medium/high/xhigh thinking levels. Orchestrator switches between Carbon (planning and read-only exploration) and Hydrogen (edits and tests) inside one task. · Why it matters: Google reports near-Carbon success on Terminal-Bench 4.1 with 24% less quota and 19% faster runs. That supports a planner/executor split you can copy in Claude Code. API pricing is $1.50/$7.50 per Mtok. In Claude Code, copy the pattern: a read-only planner subagent on a strong model hands its plan to an executor subagent on Sonnet, and you compare cost on one ticket. · https://antigravity.google/blog/gemini-4-hydrogen-in-google-antigravity/ · https://simonwillison.net/2026/Nov/12/llm-gemini/

## 🛠 Claude Code / Codex / Agents
- **Claude Code 2.1.323 changes worth acting on** — Model IDs Claude Code doesn't recognize now default to a **1M** context window instead of 200K. If you run non-Anthropic models through Claude Code, set `CLAUDE_CODE_DISABLE_1M_CONTEXT=1`, or sessions can fail every turn once full. Other changes: `CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES=1` stops the extra requests that write subagent progress summaries. `--permission-mode auto` now falls back to Manual when auto mode isn't available. Several Bash allow/deny bypasses are closed (`sudo`/`env` wrappers, `Bash(ls*)`). → Re-check any permission rules your hooks rely on. https://github.com/anthropics/claude-code/releases
- **Regression: `subagentStatusLine` removed without warning in 2.1.323** — Custom per-subagent rows (context, tokens, cost, effort) stop running with no startup warning. Workarounds: pin 2.1.322 with `DISABLE_AUTOUPDATER=1`, or render your own band above the prompt with a mod. No maintainer reply yet. → Check this if you built monitoring on it. https://github.com/anthropics/claude-code/issues/109446
- **Codex CLI 0.168.0 (Nov 13)** — Side conversations next to the main chat (`features.tui_workspace`), a model-provider picker with a default for new chats, terminal notifications via `tui.notification_method = "osc777"`, and audio attachments. → Side conversations work like Claude Code's `/btw`. Turn them on and try them for parallel questions. https://github.com/openai/codex/releases
- **Decision models as cheap routers (Gemini Decision 1 + Cloudflare pattern)** — These score closed-set choices (yes/no, multiple choice, rubrics) in about 150–250ms at $0.10/Mtok input with free output. Inputs can be text, image, audio, video or PDF, with up to 1,000 questions per request. Cloudflare showed a fast decision model doing tool selection in front of a reasoning model, cutting 6 LLM calls to 1 and about 40K tokens to 1.8K. → Replace your LLM-as-router or triage step with one of these and measure. Launched Nov 11; recap published Nov 12. https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/ · https://latent.space/p/ainews-d-day-decision-models-day/
- **Brave Search API accepts x402 agent payments (Nov 12)** — Agents pay $0.005 per request in USDC on Base with no account or API key. The flow is: HTTP 402, sign the payment, retry. → An agent can now buy search at runtime with no signup. It is also a reference implementation if you want to sell your own API to agents. https://brave.com/blog/search-api-agentic-payments/
- **Security: Fireworks AI breach exposed Notion AI chat transcripts (reported Nov 12)** — This is Fireworks' second incident in two months. The attacker's stated goal is reselling access to LLM tokens. → If you send traffic through Fireworks (directly, via OpenRouter, or via `codex-security`), rotate your keys and check usage. https://fireworks.ai/security/bulletins/october-2026-security-incident-update
